what-leaves-with-them

Agent memory on FalkorDB that checks every write before it becomes a fact. Every answer carries the graph path back to its source.

This server holds the synthetic corpus of Quillfield Billing, a fictional company (seed 42), in tenant quillfield. No real or personal data. Writes are switched off on this public demo.

  • Tool catalogue with JSON schemas
