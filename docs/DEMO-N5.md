# Demo N5: what leaves with them

An engineer at the fictional Quillfield Billing hands in a resignation. The manager usually gets a list of the
systems the person owns. This demo asks the harder question, what the company actually loses, and every answer
comes with the graph path and the records behind it. It is a handoff, not surveillance: fictional people only,
and the bridge score is the only per-person number. The same questions work before a vacation, a parental leave
or a team move.

Regenerate this page (everything below this introduction is printed by the run, nothing is typed in):

```
python -m honest_memory.corpus --seed 42 --out data/corpus      # optional: the script builds its own copy
python examples/departure_demo.py --ports 6390,6393 > docs/DEMO-N5.md
```

The sequence, as a judge would see it: (1) the same question at depth 1, what a join would list; (2) at depth 4,
what the graph adds; (3) what rests only on this person's records; (4) what nobody is connected to without them,
with the wall time; (5) who bridges teams; (6) who could take over, as candidates; (7) a question the graph cannot
answer, answered honestly; (8) the handoff plan; (9) the last-day record arrives through the write gate and the
orphaned integration answers "no current owner" instead of guessing; (10) the plan's questions for the leaver,
the handoff session that answers some of them through the same gate, and single_source / what_leaves as of a day
before and after it. Questions go through the deterministic router (no language model), so the tool and
arguments shown are exactly what ran.
